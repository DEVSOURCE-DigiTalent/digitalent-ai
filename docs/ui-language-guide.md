# Ngôn ngữ giao diện DigiTalent

## Tên gọi thống nhất

| Khái niệm | Dùng trên giao diện |
| --- | --- |
| Skill gap | Khoảng trống năng lực |
| Training batch | Đợt đào tạo |
| Owner | Chủ doanh nghiệp |
| Manager | Quản lý |
| Test / assessment | Bài đánh giá |
| Rubric | Tiêu chí đánh giá |
| Standard course | Khóa học chuẩn |
| Internal course | Khóa học nội bộ |

## Quy tắc viết

- Tiêu đề nêu đúng nội dung hoặc tác vụ, viết hoa chữ đầu câu và tên riêng.
- Nút dùng động từ rõ nghĩa: **Lưu thay đổi**, **Giao khóa học**, **Xem chi tiết**.
- Trạng thái ngắn và nhất quán: **Bản nháp**, **Đang mở**, **Đã hoàn thành**, **Quá hạn**.
- Mô tả bổ sung thông tin cần để quyết định; bỏ câu lặp lại tiêu đề hoặc giải thích quy trình hiển nhiên.
- Trạng thái trống nói rõ điều kiện hoặc bước tiếp theo. Thông báo lỗi nói điều gì chưa thực hiện được và cách thử lại.
- Không hiển thị tên API, cơ sở dữ liệu, mã triển khai, tên vai trò tiếng Anh trong ngoặc hay thuật ngữ nội bộ cho người dùng.
- Nội dung bắt buộc như điều kiện mua, hạn nộp và cảnh báo mất dữ liệu phải giữ đủ ý nghĩa khi rút gọn.
